A two-line warning to my past self: one sentence about a single moment — the last bus out of Bandung the night my grandmother called — and one sentence on what that moment cost.

## Run it

```sh
python3 main.py
```

The program writes the entry to `/output/entry.txt`: exactly two lines,
one sentence each, 1–280 characters total. It uses only the Python standard
library and produces the same bytes on every run.

## The entry

Line one warns my past self not to take the last bus out of Bandung that
night; line two traces what changed because of it — the goodbye rehearsed
on the road became a sentence never said.
